# MOOD_DESIGN_RULES — 로고 생성 무드별 조형 규칙

## 목적

이 문서는 로고 생성 프롬프트에서 `mood` 값을 단순한 분위기 설명으로 사용하는 대신, **실제 로고 디자인에 적용할 수 있는 조형 언어(Form Language)**로 변환하기 위한 규칙이다.

핵심 원칙:

- 무드를 감성적인 단어로만 설명하지 않는다.
- 각 무드는 **형태, 선, 비율, 네거티브 스페이스, 타이포그래피, 복잡도, 컬러 운용, 금지 요소**까지 구체적으로 정의한다.
- 소재를 그대로 그리는 일러스트가 아니라, 브랜드의 핵심 개념을 **추상적인 심볼 형태**로 번역한다.
- 결과물은 스티커/클립아트/이모지/일반 픽토그램이 아니라 **실제 상업 브랜드에서 사용할 수 있는 브랜드 마크**를 목표로 한다.

---

## 1. `minimal`

### 디자인 방향

불필요한 요소를 최대한 제거하고, 하나의 강한 형태만으로 브랜드를 기억하게 만드는 무드.

### 조형 언어

- 단순한 기하학적 형태
- 원, 사각형, 선, 호, 삼각형 등 기본 도형을 기반으로 구성
- 형태 요소를 1~3개 정도로 제한
- 넓은 네거티브 스페이스
- 명확하고 읽기 쉬운 실루엣
- 낮은 시각적 복잡도
- 불필요한 장식 제거
- 형태의 비율과 간격을 정교하게 조정
- 작은 크기에서도 형태가 유지되는 구조

### 선과 획

- 일정하고 안정적인 선 두께
- 지나치게 얇거나 장식적인 획은 피함
- 선을 사용할 경우 끝부분을 깔끔하게 처리
- 선과 면의 관계를 단순하게 유지
- 불필요한 외곽선과 내부 디테일을 제거

### 비율

- 안정적인 좌우 균형
- 시각적 중심이 명확한 구조
- 요소 사이의 간격을 넉넉하게 설정
- 지나치게 압축된 형태를 피함
- 작은 사이즈에서도 실루엣이 유지되도록 설계

### 네거티브 스페이스

- 적극적으로 활용
- 빈 공간 자체가 심볼의 일부가 될 수 있도록 설계
- 단순한 형태 안에서 의미가 드러나는 구조를 선호

### 타이포그래피

- 현대적인 산세리프
- 불필요하게 장식적인 폰트 금지
- 자간은 약간 여유 있게
- 심볼과 워드마크의 시각적 무게를 균형 있게 조정

### 컬러

- 1~2개의 컬러 중심
- 높은 채도의 컬러를 무조건 사용하지 않음
- 블랙, 네이비, 화이트, 뉴트럴 계열과 잘 어울림
- 컬러 자체보다 형태가 먼저 인식되도록 구성

### 피해야 할 것

- 복잡한 일러스트
- 과도한 그라데이션
- 3D 효과
- 글로시 효과
- 그림자
- 장식적인 패턴
- 지나치게 많은 요소
- 클립아트/스톡 아이콘 느낌

### 프롬프트용 규칙

```text
단순한 기하학적 형태, 넓은 네거티브 스페이스, 절제된 획,
명확한 실루엣, 낮은 시각적 복잡도, 정교한 비율,
최소한의 형태 요소, 현대적인 산세리프 타이포그래피,
불필요한 장식 없이 강한 하나의 브랜드 아이덴티티를 형성할 것.
```

## 2. `natural`

### 디자인 방향

자연의 유기적인 형태와 흐름을 현대적인 브랜드 심볼로 추상화한다.

### 조형 언어

- 부드러운 곡선
- 유기적인 비율
- 자연스러운 비대칭
- 잎, 물결, 바람, 성장, 흐름 등의 특징을 직접 묘사하지 않고 추상화
- 딱딱한 기하학보다 자연스러운 형태 변화
- 형태가 서로 자연스럽게 이어지는 구조
- 편안하고 안정적인 실루엣
- 여백을 활용한 부드러운 조형

### 선과 획

- 부드러운 곡률
- 획 두께에 자연스러운 변화가 있을 수 있음
- 지나치게 기계적인 직선은 최소화
- 끝부분은 날카롭기보다 자연스럽게 마감
- 손으로 만든 듯한 불규칙성을 아주 미세하게 허용하되 조잡하지 않게 유지

### 비율

- 완벽한 대칭보다 자연스러운 균형
- 약간의 비대칭 허용
- 둥글고 편안한 비율
- 지나치게 날카롭거나 공격적인 각도는 피함

### 네거티브 스페이스

- 형태 사이의 빈 공간이 숨 쉬는 느낌을 주도록 구성
- 좁게 막힌 구조보다 열린 구조 선호
- 자연의 흐름이나 성장 방향을 빈 공간으로 표현할 수 있음

### 타이포그래피

- 부드러운 산세리프
- 지나치게 굵고 공격적인 폰트 금지
- 적당한 자간
- 둥근 형태의 글자와 조화되는 워드마크
- 전체적으로 편안하고 친근한 인상

### 컬러

- 그린, 세이지, 올리브, 베이지, 크림, 브라운, 블루그린 계열과 잘 어울림
- 낮거나 중간 정도의 채도
- 자연스러운 톤 조합
- 형광색이나 과도한 네온 컬러는 피함

### 피해야 할 것

- 흔한 잎사귀 아이콘
- 단순한 나뭇잎 그림
- 스톡 에코 아이콘
- 지나치게 대칭적인 기하학
- 과도한 장식
- 자연 사진 느낌
- 사실적인 식물 일러스트

### 프롬프트용 규칙

```text
부드러운 곡선, 유기적인 비율, 자연스러운 비대칭,
편안한 실루엣, 열린 네거티브 스페이스,
자연의 흐름과 성장을 추상적인 형태로 표현,
기계적인 직선과 과도한 대칭을 최소화,
세련되고 현대적인 자연주의 브랜드 아이덴티티로 설계할 것.
```

## 3. `tech`

### 디자인 방향

기술, 정밀함, 연결, 데이터, 미래, 시스템을 추상적인 기하학으로 표현한다.

### 조형 언어

- 정밀한 기하학
- 모듈러 구조
- 반복 가능한 형태
- 그리드 기반 구성
- 연결과 결합을 암시하는 구조
- 날카로운 네거티브 스페이스
- 미래적인 비율
- 단순하지만 구조적으로 정교한 심볼

### 선과 획

- 일정한 선 두께
- 정밀한 직선과 곡선
- 날카로운 절단면
- 모듈 간 간격을 일정하게 유지
- 지나치게 복잡한 회로 패턴은 피함

### 비율

- 정확한 수학적 균형
- 모듈 단위가 반복되는 구조
- 수평/수직/대각선 축을 명확하게 사용
- 약간의 비대칭을 사용하더라도 의도적으로 설계된 느낌을 유지

### 네거티브 스페이스

- 절단면
- 연결부
- 데이터 흐름
- 이니셜
- 숨겨진 기호

등을 표현하는 핵심 장치로 적극 활용한다.

### 타이포그래피

- 현대적인 산세리프
- 기하학적 폰트
- 적당히 넓은 자간
- 날카롭고 정밀한 인상
- 지나치게 미래적인 장식 폰트는 피함

### 컬러

- 블루, 네이비, 시안, 바이올렛, 딥 퍼플 등
- 블랙/화이트 기반에 포인트 컬러를 사용하는 방식
- 필요할 경우 제한적인 그라데이션 허용
- 네온 효과는 최소화

### 피해야 할 것

- 흔한 회로 기판 아이콘
- 클라우드 아이콘
- AI 뇌 모양
- 과도한 육각형 패턴
- 사이버펑크 스타일
- 과도한 글로우
- 3D 렌더링
- 게임 로고 같은 느낌

### 프롬프트용 규칙

```text
정밀한 기하학, 모듈러 구조, 그리드 기반 조형,
날카로운 네거티브 스페이스, 미래적인 비율,
정확한 선과 간격, 연결과 시스템을 암시하는 구조,
현대적인 테크 브랜드 아이덴티티,
과도한 회로 패턴이나 사이버펑크 장식 없이 세련되고 절제된 형태.
```

## 4. `premium`

### 디자인 방향

고급스러움을 장식으로 표현하지 않고 **비율, 여백, 타이포그래피, 절제된 조형**으로 표현한다.

### 조형 언어

- 정교한 비율
- 얇고 우아한 형태
- 절제된 곡선
- 단순하지만 독창적인 심볼
- 넓은 여백
- 낮은 시각적 복잡도
- 형태의 완성도와 균형을 최우선으로 함

### 선과 획

- 얇거나 중간 정도의 정교한 획
- 획 두께의 대비를 제한적으로 사용
- 끝부분은 정교하고 깨끗하게 처리
- 과도하게 장식적인 세리프는 피함

### 비율

- 매우 정교한 비율
- 심볼과 워드마크의 시각적 무게를 섬세하게 조정
- 요소 사이에 충분한 공간 확보
- 로고가 작게 배치되어도 고급스러운 인상을 유지

### 네거티브 스페이스

- 넓고 의도적인 여백
- 빈 공간을 디자인의 중요한 요소로 취급
- 형태를 억지로 채우지 않음

### 타이포그래피

- 고급스러운 산세리프 또는 절제된 세리프
- 넓은 자간
- 얇거나 중간 굵기
- 글자 사이의 균형을 매우 중요하게 처리
- 워드마크 자체가 브랜드 자산처럼 보이도록 설계

### 컬러

- 블랙
- 아이보리
- 딥 네이비
- 차콜
- 딥 그린
- 샴페인
- muted gold

등 제한적인 팔레트를 사용한다.

### 피해야 할 것

- 금색을 무조건 사용하는 방식
- 과도한 메탈릭 효과
- 보석 같은 3D 렌더링
- 화려한 장식
- 과도한 그라데이션
- 럭셔리 패션 로고를 그대로 모방한 느낌

### 프롬프트용 규칙

```text
정교한 비율, 얇고 우아한 형태, 넓은 자간,
절제된 대비, 고급스러운 여백,
낮은 시각적 복잡도, 세련된 워드마크,
형태 자체의 완성도로 프리미엄 이미지를 전달할 것.
장식이나 3D 효과가 아니라 비율과 여백으로 고급스러움을 표현할 것.
```

## 5. `playful`

### 디자인 방향

밝고 친근하며 기억하기 쉽지만, 어린이용 캐릭터나 스티커처럼 보이지 않는 현대적인 브랜드 개성을 만든다.

### 조형 언어

- 단순하지만 개성 있는 형태
- 리듬감 있는 비율
- 부드러운 곡선
- 약간의 비대칭
- 예상하지 못한 형태 결합
- 기억하기 쉬운 실루엣
- 한두 개의 재미있는 시각적 반전

### 선과 획

- 부드럽고 명확한 획
- 둥근 끝처리
- 지나치게 얇은 선은 피함
- 형태가 작아져도 유머러스한 특징이 유지되도록 설계

### 비율

- 약간 과장된 비율을 제한적으로 허용
- 원형과 둥근 모서리 적극 활용
- 요소 간 리듬감 있는 크기 차이
- 완벽한 대칭보다 의도적인 불균형 선호

### 네거티브 스페이스

- 숨겨진 얼굴
- 이니셜
- 작은 도형
- 예상하지 못한 형태

등을 활용할 수 있음.

단, 숨은 요소가 너무 복잡해지지 않도록 한다.

### 타이포그래피

- 둥근 산세리프
- 친근하고 현대적인 글자
- 약간의 커스텀 형태 허용
- 자간은 너무 넓지 않게 조정
- 글자 자체에 작은 개성을 부여할 수 있음

### 컬러

- 밝은 블루
- 코랄
- 옐로우
- 라임
- 핑크
- 오렌지
- 밝은 퍼플

등을 사용할 수 있다.

단, 여러 색상을 동시에 과도하게 사용하지 않는다.

### 피해야 할 것

- 캐릭터
- 얼굴
- 이모지
- 스티커
- 만화
- 유아용 그래픽
- 과도한 컬러풀함
- 장난감 같은 3D 렌더링

### 프롬프트용 규칙

```text
단순하지만 개성 있는 형태, 리듬감 있는 비율,
부드러운 곡선, 의도적인 비대칭,
기억하기 쉬운 독특한 실루엣,
작은 시각적 반전이나 네거티브 스페이스를 활용,
밝고 친근하지만 유치하지 않은 현대적인 브랜드 아이덴티티로 설계할 것.
```

# 6. 공통 브랜드 마크 품질 규칙

모든 mood에 아래 규칙을 공통으로 적용한다.

```text
당신은 10년 이상의 경력을 가진 시니어 브랜드 아이덴티티 디자이너입니다.

단순히 소재를 그림으로 묘사하지 말고,
브랜드의 핵심 개념과 소재를 하나의 기억하기 쉬운 조형 언어로 추상화하세요.

심볼의 비율, 선의 두께, 곡률, 네거티브 스페이스,
심볼과 워드마크 사이의 거리, 글자의 자간과 시각적 무게를 정교하게 조정하세요.

로고는 실제 웹사이트, 앱 아이콘, 패키지, 인쇄물,
간판 및 소셜 미디어 프로필에서 사용할 수 있어야 합니다.

작은 크기에서도 명확한 실루엣이 유지되어야 합니다.

스티커, 클립아트, 이모지, 캐릭터,
일반적인 스톡 아이콘, 픽토그램, 일러스트처럼 보이지 않게 하세요.

불필요한 장식, 과도한 디테일, 과도한 3D,
과도한 그림자, 글로우, 광택 효과는 사용하지 마세요.

브랜드 로고로서의 독창성과 단순성을 동시에 유지하세요.
```

# 8. `buildImagePrompt()`에서 적용

기존에 단순히:

```js
`분위기: ${mood.hint}.`
```

만 사용하고 있다면 아래처럼 변경한다.

```js
import { MOOD_DESIGN_RULES } from "../src/lib/moodDesignRules.js";
```

그리고:

```js
const moodRule =
  MOOD_DESIGN_RULES[brief.mood] || "";
```

프롬프트에:

```js
`브랜드 분위기: ${mood.hint}.`,
`조형 언어: ${moodRule}.`,
```

를 추가한다.

# 9. 최종적으로 모델에 전달되는 구조

최종 프롬프트는 다음 순서를 권장한다.

```text
1. 역할
   ↓
2. 브랜드/업종
   ↓
3. 로고 형태
   ↓
4. 핵심 소재
   ↓
5. 소재의 추상화 방법
   ↓
6. Mood Design Rule
   ↓
7. 브랜드 마크 품질 규칙
   ↓
8. 타이포그래피
   ↓
9. 컬러
   ↓
10. 레이아웃
   ↓
11. 금지 요소
```

이 순서를 유지하면 `minimal`, `natural`, `tech`, `premium`, `playful`이 단순히 **색깔만 다른 로고**가 아니라 실제로 **조형 언어가 다른 로고**로 나오게 된다.

## 핵심

현재 시스템에서 가장 중요한 변경은:

```js
분위기: ${mood.hint}
```

에서 끝내지 않고,

```js
분위기: ${mood.hint}
조형 언어: ${MOOD_DESIGN_RULES[brief.mood]}
```

로 확장하는 것이다.

즉,

**Mood = 감정**

이 아니라

**Mood = 실제 디자인 결정의 집합**

으로 바꾸는 것이 목적이다.
